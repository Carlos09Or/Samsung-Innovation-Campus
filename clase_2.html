DICCIONARIOS AVANZADOS ● GUÍA DE REPASO

setdefault() para inventarios

En un inventario, puedes obtener una cantidad existente o crear un producto que todavía no aparece.

EN POCAS PALABRAS
  • Si ya existe, conserva el stock actual.
  • Si falta, inserta el stock inicial que indiques.
PYTHON
inventario = {"manzanas": 10, "peras": 5}
print(inventario.setdefault("manzanas", 0))
print(inventario.setdefault("naranjas", 0))
print(inventario["naranjas"])
↳ SALIDA ESPERADA
10
0
0
◆ IDEA CLAVE

No confundas setdefault con update: uno solo crea si no existe; el otro también reemplaza.

update() para precios

Actualiza varias claves existentes y añade otras en una sola llamada.

EN POCAS PALABRAS
  • cafe y pan se actualizan.

  • te se conserva sin cambios.

precios = {"cafe": 3.50, "te": 2.00, "pan": 1.00}

print(precios["cafe"])

DICCIONARIOS AVANZADOS ● GUÍA DE REPASO

pop() frente a popitem()

Ambos devuelven lo eliminado, pero seleccionan el elemento de forma diferente.

EN POCAS PALABRAS
  • pop("rol") quita la clave solicitada.
  • popitem() quita el último par insertado (Python 3.7+).
  • En diccionario vacío, popitem() produce KeyError.
PYTHON
usuario = {"id": 1024, "nombre": "Sofía", "rol": "Editor", "activo": True}
print(usuario.pop("rol"))
print(usuario.popitem())
↳ SALIDA ESPERADA
Editor
('activo', True)
◆ IDEA CLAVE

Recuerda que popitem() devuelve una tupla (clave, valor).

DICCIONARIOS AVANZADOS ● GUÍA DE REPASO

¿Cómo evitar errores al retirar claves?

Puedes dar a pop() un valor por defecto cuando no existe la clave.

EN POCAS PALABRAS
  • pop(clave) sin defecto lanza KeyError si falta.
  • pop(clave, defecto) devuelve el defecto en ese caso.
PYTHON
usuario = {"nombre": "Sofía"}
rol = usuario.pop("rol", "Sin rol")
print(rol)
print(usuario)
↳ SALIDA ESPERADA
Sin rol
{'nombre': 'Sofía'}

Este es un refuerzo útil de la idea de «eliminación segura» mencionada en el Colab.

MÓDULOS ● GUÍA DE REPASO

¿Qué es un módulo?

Un módulo es un archivo o biblioteca de Python que ofrece funciones, objetos y herramientas reutilizables.

EN POCAS PALABRAS
  • import math importa el módulo completo.
  • import math as m crea un alias.
  • from collections import defaultdict importa un objeto concreto.
PYTHON
import math as m
from collections import defaultdict
print(m.sqrt(81))
print(type(defaultdict(int)).__name__)
↳ SALIDA ESPERADA
9.0
defaultdict
◆ IDEA CLAVE

as no cambia el módulo: solo te permite escribir un nombre más corto.

MÓDULOS ● GUÍA DE REPASO

defaultdict(int) · Contar letras

defaultdict crea automáticamente el valor inicial cuando accedes a una clave inexistente.

EN POCAS PALABRAS
  • Con int, el valor inicial es 0.
  • Puedes incrementar conteo[letra] sin comprobar antes si existe.
PYTHON
from collections import defaultdict
conteo = defaultdict(int)
for letra in "Banana":
    conteo[letra] += 1
print(dict(conteo))
↳ SALIDA ESPERADA
{'B': 1, 'a': 3, 'n': 2}
↪ ACLARACIÓN DEL COLAB El Colab comenta una salida con b minúscula para el texto «Banana». Python distingue mayúsculas: la clave correcta es B.
MÓDULOS ● GUÍA DE REPASO

defaultdict(list) · Agrupar frutas

Con list, cada clave nueva recibe una lista vacía que puedes llenar.

EN POCAS PALABRAS
  • Un patrón útil para agrupar registros por categoría.
  • Se combina con .append() del tema de listas.
PYTHON
from collections import defaultdict
pares = [("rojo", "manzana"), ("amarillo", "plátano"),
         ("rojo", "fresa")]
agrupados = defaultdict(list)
for color, fruta in pares:
    agrupados[color].append(fruta)
print(dict(agrupados))
↳ SALIDA ESPERADA
{'rojo': ['manzana', 'fresa'], 'amarillo': ['plátano']}
◆ IDEA CLAVE

La elección int o list determina qué dato se crea automáticamente.

datetime · Fechas y diferencias

El módulo datetime permite crear fechas y restarlas para calcular intervalos.

EN POCAS PALABRAS
  • date(año, mes, día) representa una fecha.

  • La resta de dos fechas devuelve timedelta, que tiene .days.
PYTHON
import datetime as dt
inicio = dt.date(2026, 1, 1)
fin = dt.date(2026, 1, 11)
print((fin - inicio).days)

10

03 / Conjuntos en acción

Comparar grupos y deduplicar información.

CONJUNTOS ● GUÍA DE REPASO

De una lista repetida a participantes únicos

Los conjuntos guardan una sola aparición de cada valor.

EN POCAS PALABRAS
  • En el Colab se limpian listas de asistentes.
  • No uses índices numéricos ni des por hecho el orden de impresión.
PYTHON
asistentes = ["Ana", "Carlos", "Ana", "Sofia", "Carlos", "David"]
unicos = set(asistentes)
print(len(asistentes))
print(len(unicos))
↳ SALIDA ESPERADA
6
4
◆ IDEA CLAVE

La conversión no altera la lista original.

CONJUNTOS ● GUÍA DE REPASO

Unión | · Grupos de mañana y tarde

Reúne alumnos inscritos en al menos uno de los dos grupos.

EN POCAS PALABRAS
  • Evita duplicados como Sofía que aparece en ambos.
  • | es equivalente a .union().
PYTHON
manana = {"Ana", "Carlos", "Sofia"}
tarde = {"Sofia", "David", "Elena"}
todos = manana | tarde
print(len(todos))
↳ SALIDA ESPERADA
5
◆ IDEA CLAVE

La unión corresponde a una condición inclusiva: A o B (o ambos).

CONJUNTOS ● GUÍA DE REPASO

Intersección & · Dos cursos

Encuentra alumnos matriculados simultáneamente en Python e IA.

EN POCAS PALABRAS
  • & selecciona solo lo que comparten.
  • .intersection() obtiene el mismo resultado.
PYTHON
python = {"Ana", "Erick", "David", "Elena"}
ia = {"David", "Elena", "Jhoandry", "Gabriela"}
print((python & ia) == {"David", "Elena"})
↳ SALIDA ESPERADA
True
◆ IDEA CLAVE

Este es el caso de estudiantes en ambos cursos del material original.

CONJUNTOS ● GUÍA DE REPASO

Diferencia - · Un equipo sin el otro

Qué personas están en el grupo rojo, pero no en el azul.

EN POCAS PALABRAS
  • La diferencia depende de cuál conjunto va primero.
  • A - B no significa «los que son distintos en ambos».
PYTHON
rojo = {"Ana", "Carlos", "Sofia"}
azul = {"Sofia", "David", "Elena"}
print(rojo - azul == {"Ana", "Carlos"})
↳ SALIDA ESPERADA
True
◆ IDEA CLAVE

Para los exclusivos de AMBOS grupos necesitas diferencia simétrica.

CONJUNTOS ● GUÍA DE REPASO

Diferencia simétrica ^

Recoge los miembros que pertenecen a un conjunto o al otro, pero no a ambos.

EN POCAS PALABRAS
  • A ^ B elimina los elementos compartidos.
  • También se llama .symmetric_difference().
PYTHON
rojo = {"Ana", "Carlos", "Sofia"}
azul = {"Sofia", "David", "Elena"}
solo_un_grupo = rojo ^ azul
print(len(solo_un_grupo))
print("Sofia" in solo_un_grupo)
↳ SALIDA ESPERADA
4
False
◆ IDEA CLAVE

Diferencia -: solo A. Diferencia simétrica ^: exclusivos de A y B.

CONJUNTOS ● GUÍA DE REPASO

Tabla mental · Operadores de conjuntos

Asocia cada símbolo con una pregunta concreta.

EN POCAS PALABRAS
  • A | B → ¿quién está en alguno de los dos?
  • A & B → ¿quién aparece en ambos?
  • A - B → ¿quién está solo en A?
  • A ^ B → ¿quién aparece en uno de los dos pero no en ambos?
PYTHON
A = {1, 2, 3}
B = {3, 4}
print(len(A | B), len(A & B), len(A - B), len(A ^ B))
↳ SALIDA ESPERADA
4 1 2 3
◆ IDEA CLAVE

La diferencia simétrica se añade explícitamente en la Clase 2.

04 / Matrices con listas

Filas, columnas y dos niveles de índices.

MATRICES ● GUÍA DE REPASO

Lista bidimensional: la idea

Una matriz representada con listas es una lista cuyos elementos también son listas.

EN POCAS PALABRAS
  • La lista exterior contiene filas.
  • Cada lista interior contiene las columnas de esa fila.
  • No es un tipo de dato nuevo: es una estructura anidada.
PYTHON
matriz = [
    [1, 2, 3],
    [4, 5, 6],
    [7, 8, 9]
]
print(len(matriz))
↳ SALIDA ESPERADA
3
◆ IDEA CLAVE

El ejemplo 3×3 aparece en las celdas de listas bidimensionales.

MATRICES ● GUÍA DE REPASO

matriz[fila][columna]

Cada par de corchetes selecciona un nivel: primero la fila, luego la posición dentro de ella.

EN POCAS PALABRAS
  • matriz[1] es toda la segunda fila.
  • matriz[1][2] es el tercer elemento de esa fila.
  • Los dos índices empiezan en cero.
PYTHON
matriz = [[10, 20, 30], [40, 50, 60], [70, 80, 90]]
print(matriz[1])
print(matriz[1][2])
↳ SALIDA ESPERADA
[40, 50, 60]
60
◆ IDEA CLAVE

No confundas fila 1 con primera fila: en Python es la segunda.

MATRICES ● GUÍA DE REPASO

for anidados · Recorrer cada celda

El bucle externo recorre las filas; el interno recorre los valores de la fila.

EN POCAS PALABRAS
  • Cada iteración del for externo entrega una lista.
  • Cada iteración del interno entrega un elemento de esa lista.
PYTHON
matriz = [[1, 2], [3, 4]]
for fila in matriz:
    for numero in fila:
        print(numero, end=" ")
    print()
↳ SALIDA ESPERADA
1 2 
3 4
◆ IDEA CLAVE

La última instrucción print() cambia de línea al finalizar una fila.

MATRICES ● GUÍA DE REPASO

Modificar una celda

Una lista bidimensional puede modificarse usando ambos índices.

EN POCAS PALABRAS
  • matriz[0][0] = 999 reemplaza la primera casilla.
  • El resto de la estructura no cambia.
PYTHON
matriz = [[10, 20, 30], [40, 50, 60]]
matriz[0][0] = 999
print(matriz[0])
↳ SALIDA ESPERADA
[999, 20, 30]
◆ IDEA CLAVE

Una matriz de listas puede tener filas de diferente longitud; no necesariamente es rectangular.

MATRICES ● GUÍA DE REPASO

Tic-tac-toe · Un tablero como matriz

Una cuadrícula de juego también puede modelarse con listas anidadas.

EN POCAS PALABRAS
  • Cada fila contiene tres casillas.
  • tablero[1][1] marca la casilla central.
  • La segunda asignación a una casilla reemplaza la anterior.
PYTHON
tablero = [[" ", " ", " "], [" ", " ", " "], [" ", " ", " "]]
tablero[1][1] = "X"
print(tablero[1])
↳ SALIDA ESPERADA
[' ', 'X', ' ']
↪ ACLARACIÓN DEL COLAB En el Colab se indica en un comentario la posición (1, 0), pero el código modifica (1, 1). Además, otra demostración vuelve a escribir en la misma casilla.
MATRICES ● GUÍA DE REPASO

Tic-tac-toe · ¿Qué pasa si sobrescribes?

Un valor nuevo asignado a una misma casilla reemplaza al anterior.

EN POCAS PALABRAS
  • Una lista no recuerda el valor anterior de esa posición.
  • Para evitar jugadas ilegales habría que comprobar si la casilla está vacía (refuerzo).
PYTHON
tablero = [[" ", " ", " "], [" ", " ", " "], [" ", " ", " "]]
tablero[0][2] = "X"
tablero[0][2] = "O"
print(tablero[0][2])

O

EN POCAS PALABRAS

tablero = [

RETO FINAL ● GUÍA DE REPASO

Primero, diseña el algoritmo

Traducimos la consigna a pasos claros antes de programarla.

✦ DESAFÍO · INTÉNTALO SIN MIRAR

¿Por qué usamos set y no list para guardar los premios encontrados?

  • 1. Crear un set() vacío.
  • 2. Recorrer cada fila de la matriz.
  • 3. Recorrer cada premio de la fila.
  • 4. Añadirlo al conjunto con .add().
  • 5. Mostrar el resultado.
PYTHON
# Un set ignora duplicados automáticamente.
unicos = set()
for premio in ["oro", "oro", "plata"]:
    unicos.add(premio)
print(len(unicos))  # 2
PISTA / IDEA CLAVE

Pensar la estructura de datos adecuada simplifica el programa.

RETO FINAL ● GUÍA DE REPASO

Solución · Buscar premios únicos

Esencialmente la misma estrategia de la respuesta que aparece en el Colab.

EN POCAS PALABRAS
  • Bucle externo → filas.
  • Bucle interno → premios.
  • set.add() garantiza unicidad.
PYTHON
tablero = [["oro", "plata", "oro"],
           ["bronce", "diamante", "plata"],
           ["oro", "bronce", "diamante"]]
premios_unicos = set()
for fila in tablero:
    for premio in fila:
        premios_unicos.add(premio)
print(len(premios_unicos))
↳ SALIDA ESPERADA
4
◆ IDEA CLAVE

Los cuatro tipos son oro, plata, bronce y diamante; el orden al imprimir un set varía.

RETO FINAL ● GUÍA DE REPASO

Extensión · ¿Cuántas veces aparece cada premio?

Refuerzo opcional: al cambiar la estructura de datos, cambia la pregunta que puedes responder.

EN POCAS PALABRAS
  • Con set sabes qué premios existen.
  • Con defaultdict(int) sabes cuántas veces aparece cada premio.
PYTHON
from collections import defaultdict
tablero = [["oro", "plata"], ["oro", "bronce"]]
conteo = defaultdict(int)
for fila in tablero:
    for premio in fila:
        conteo[premio] += 1
print(dict(conteo))
↳ SALIDA ESPERADA
{'oro': 2, 'plata': 1, 'bronce': 1}
◆ IDEA CLAVE

Este ejemplo adicional conecta los dos grandes bloques de la Clase 2.
