SIGUIENTE BLOQUE

01 / Anatomía de una función

Definir una vez, usar muchas veces.

ANATOMÍA ● GUÍA DE REPASO

Las cinco partes de una función

Cada función tiene la misma estructura, por pequeña que sea.

EN POCAS PALABRAS
  • def anuncia que vas a definir una función.
  • El nombre (saludar) es con lo que luego la llamas.
  • Los parámetros van entre paréntesis: nombre.
  • El cuerpo va indentado; return entrega el resultado.
PYTHON
def saludar(nombre):  # 'nombre' es un parámetro
    """Esta función saluda a la persona con el nombre dado."""
    return f"Hola, {nombre}!"  # valor de retorno

mensaje = saludar("Ana")  # "Ana" es el argumento
print(mensaje)
↳ SALIDA ESPERADA
Hola, Ana!
◆ IDEA CLAVE

Definir la función no la ejecuta: solo se ejecuta cuando la llamas con saludar(...).

ANATOMÍA ● GUÍA DE REPASO

Definir no es ejecutar

Python lee la definición y la guarda; el cuerpo corre en cada llamada.

EN POCAS PALABRAS
  • Al definir, Python solo recuerda la receta.
  • Cada llamada nombre() vuelve a ejecutar el cuerpo completo.
  • Por eso puedes llamar la misma función muchas veces.
PYTHON
def anunciar():
    print("¡Llegó el café!")

print("Antes de llamar")
anunciar()
anunciar()
print("Después de llamar")
↳ SALIDA ESPERADA
Antes de llamar
¡Llegó el café!
¡Llegó el café!
Después de llamar
◆ IDEA CLAVE

Predice la salida antes de ejecutar: ¿cuántas veces aparece el anuncio?

ANATOMÍA ● GUÍA DE REPASO

Parámetros frente a argumentos

Son dos caras de lo mismo: el hueco y el valor que lo llena.

EN POCAS PALABRAS
  • Parámetro: el nombre en la definición (base, altura).
  • Argumento: el valor real en la llamada (10, 5).
  • El parámetro solo existe dentro de la función.
PYTHON
# DEFINICIÓN: 'base' y 'altura' son los PARÁMETROS
def calcular_area_triangulo(base, altura):
    area = 0.5 * base * altura
    return area

# LLAMADA: 10 y 5 son los ARGUMENTOS
area_del_triangulo = calcular_area_triangulo(10, 5)
print(area_del_triangulo)
↳ SALIDA ESPERADA
25.0
◆ IDEA CLAVE

Truco para recordarlo: el parámetro está en la plantilla; el argumento es lo que aportas al llamar.

ANATOMÍA ● GUÍA DE REPASO

Ejemplo · Preparar un café ☕

Eres barista: la receta es la función y el pedido del cliente son los argumentos.

EN POCAS PALABRAS
  • Nombre: preparar_cafe.
  • Parámetros: tipo_cafe y cantidad_leche.
  • Cuerpo: los pasos; aquí, un print.
  • Retorno: el café listo que entregas.
PYTHON
def preparar_cafe(tipo_cafe, cantidad_leche):
    print(f"Preparando un {tipo_cafe} con {cantidad_leche}.")
    return "¡Aquí está tu café!"

cafe_listo = preparar_cafe("capuchino", "mucha leche")
print(cafe_listo)
↳ SALIDA ESPERADA
Preparando un capuchino con mucha leche.
¡Aquí está tu café!
↪ ACLARACIÓN DEL COLAB En el Colab la salida guardada dice «Preparando un espresso…», pero el código llama con "capuchino": esa salida es de una ejecución anterior. La salida real es la de aquí.
ANATOMÍA ● GUÍA DE REPASO

Ejemplo · Área de un terreno

Ahora eres ingeniero: la fórmula es la función y las medidas reales son los argumentos.

EN POCAS PALABRAS
  • Parámetros: largo y ancho.
  • Cuerpo: multiplicar largo * ancho.
  • El resultado se guarda en una variable para usarlo después.
PYTHON
def calcular_area_rectangulo(largo, ancho):
    """Calcula el área de un rectángulo."""
    area = largo * ancho
    return area

area_terreno = calcular_area_rectangulo(40, 20)
print(f"El área del terreno es de {area_terreno} metros cuadrados.")
↳ SALIDA ESPERADA
El área del terreno es de 800 metros cuadrados.
↪ ACLARACIÓN DEL COLAB El comentario del Colab dice «20 y 15 son los argumentos», pero la llamada usa 40 y 20; por eso el resultado es 800.
ANATOMÍA ● GUÍA DE REPASO

Repaso · La máquina de hacer jugo 🍹

El mismo esquema en otro contexto: ingredientes, pasos y producto final.

EN POCAS PALABRAS
  • fruta y azucar_cucharadas son los parámetros.
  • "naranja" y 2 son los argumentos.
  • El print ocurre dentro; el return sale de la función.
PYTHON
def hacer_jugo(fruta, azucar_cucharadas):
    print(f"Mezclando {fruta} con {azucar_cucharadas} cucharadas de azúcar.")
    return f"Aquí está tu jugo de {fruta}."

jugo_listo = hacer_jugo("naranja", 2)
print(jugo_listo)
↳ SALIDA ESPERADA
Mezclando naranja con 2 cucharadas de azúcar.
Aquí está tu jugo de naranja.
◆ IDEA CLAVE

Cambia los argumentos (por ejemplo "mango", 0) y vuelve a ejecutar.

ANATOMÍA ● GUÍA DE REPASO

Docstring: documenta tu función

El texto entre triples comillas justo debajo de def explica qué hace la función.

EN POCAS PALABRAS
  • Se llama docstring y es opcional, pero muy recomendable.
  • Python lo guarda en función.__doc__.
  • help(función) lo muestra.
PYTHON
def calcular_area_rectangulo(largo, ancho):
    """Calcula el área de un rectángulo."""
    return largo * ancho

print(calcular_area_rectangulo.__doc__)
↳ SALIDA ESPERADA
Calcula el área de un rectángulo.
◆ IDEA CLAVE

Una buena docstring responde: ¿qué recibe y qué devuelve?

SIGUIENTE BLOQUE

02 / Parámetros y argumentos

Cómo llegan los datos a una función.

PARÁMETROS ● GUÍA DE REPASO

Parámetros posicionales obligatorios

Python asigna los argumentos por su posición: el primero al primer parámetro, y así sucesivamente.

EN POCAS PALABRAS
  • El orden importa: restar(5, 15) no es restar(15, 5).
  • Si falta un argumento, Python lanza TypeError.
PYTHON
def restar(a, b):
    return a - b

print(restar(5, 15))   # a=5, b=15
try:
    restar(10)         # falta b
except TypeError as error:
    print("Error:", error)
↳ SALIDA ESPERADA
-10
Error: restar() missing 1 required positional argument: 'b'
↪ ACLARACIÓN DEL COLAB En el Colab el comentario dice «a=10, b=6», pero la llamada es restar(5, 15): a vale 5, b vale 15 y el resultado es -10.
PARÁMETROS ● GUÍA DE REPASO

Argumentos por palabra clave

Escribes el nombre del parámetro al llamar, y el orden deja de importar.

EN POCAS PALABRAS
  • restar(b=19, a=26) asigna por nombre, no por posición.
  • Hace las llamadas más claras cuando hay muchos parámetros.
PYTHON
def restar(a, b):
    return a - b

print(restar(b=19, a=26))
print(restar(a=26, b=19))
↳ SALIDA ESPERADA
7
7
◆ IDEA CLAVE

Las dos llamadas dan lo mismo: lo que manda es el nombre, no el lugar.

PARÁMETROS ● GUÍA DE REPASO

Parámetros con valor por defecto

Si no envías ese argumento, la función usa el valor que trae de fábrica.

EN POCAS PALABRAS
  • mensaje="Hola" define el valor por defecto.
  • Si lo envías, se sobrescribe.
  • Los parámetros con valor por defecto van al final.
PYTHON
def saludar(nombre, mensaje="Hola"):
    return f"{mensaje}, {nombre}!"

print(saludar("Ana"))
print(saludar("Juan", mensaje="Hola de nuevo"))
print(saludar("Pedro", mensaje="Buenos días"))
↳ SALIDA ESPERADA
Hola, Ana!
Hola de nuevo, Juan!
Buenos días, Pedro!
↪ ACLARACIÓN DEL COLAB En el Colab solo se ve 'Hola de nuevo, Pedro!' porque una celda muestra únicamente el valor de su última línea. Para ver todas las llamadas, usa print. Además, un comentario dice «Hola de nuevo, Ana!» para la llamada con «Juan».
PARÁMETROS ● GUÍA DE REPASO

El orden de los nombres manda

Lo que cuenta es cómo se llaman los parámetros en la definición, no cómo se llamen tus variables.

EN POCAS PALABRAS
  • Por posición: el primer valor va al primer parámetro.
  • Por palabra clave: cada valor va al parámetro con ese nombre.
  • Un nombre engañoso (restar que hace b - a) confunde: nombra según lo que hace.
PYTHON
def restar(a, b):
    return a - b

print(restar(10, 4))      # a=10, b=4
print(restar(4, 10))      # a=4,  b=10
print(restar(b=4, a=10))  # por nombre
↳ SALIDA ESPERADA
6
-6
6
↪ ACLARACIÓN DEL COLAB El Colab define una versión restar(b, a) con el comentario «'10' es a, '5' es b» (no coincide con el código) y otra restar(a, b) que devuelve b - a. Aquí se usa una sola versión coherente.
PARÁMETROS ● GUÍA DE REPASO

Valor por defecto con decisión

Un parámetro por defecto puede cambiar el comportamiento de la función.

EN POCAS PALABRAS
  • Sin idioma, la función usa "es".
  • Con idioma="en", responde en inglés.
  • El if dentro del cuerpo decide qué devolver.
PYTHON
def saludar_con_idioma(nombre, idioma="es"):
    if idioma == "es":
        return f"Hola, {nombre}!"
    else:
        return f"Hello, {nombre}!"

print(saludar_con_idioma("María"))
print(saludar_con_idioma("John", idioma="en"))
↳ SALIDA ESPERADA
Hola, María!
Hello, John!
◆ IDEA CLAVE

Los valores por defecto hacen que la llamada más común sea también la más corta.

PARÁMETROS ● GUÍA DE REPASO

Devolver varios valores

Una función puede procesar datos y entregar varios resultados a la vez.

EN POCAS PALABRAS
  • El parámetro calificaciones espera una lista.
  • return promedio, maxima, minima devuelve una tupla.
  • Al llamar, la desempaquetas en tres variables.
PYTHON
def analizar_calificaciones(calificaciones):
    """Calcula el promedio, la nota más alta y la más baja."""
    promedio = sum(calificaciones) / len(calificaciones)
    maxima = max(calificaciones)
    minima = min(calificaciones)
    return promedio, maxima, minima

notas_curso = [85, 90, 78, 92, 88]
prom, alta, baja = analizar_calificaciones(notas_curso)
print(f"Promedio: {prom}")
print(f"Nota máxima: {alta}")
print(f"Nota mínima: {baja}")
↳ SALIDA ESPERADA
Promedio: 86.6
Nota máxima: 92
Nota mínima: 78
◆ IDEA CLAVE

Parámetro: calificaciones (lo que espera). Argumento: notas_curso (la lista real que entregas).

PARÁMETROS ● GUÍA DE REPASO

Reglas para no equivocarte

Tres reglas que evitan la mayoría de errores al llamar funciones.

EN POCAS PALABRAS
  • Primero van los argumentos posicionales y después los de palabra clave: saludar("Ana", mensaje="Hola").
  • En la definición, los parámetros con valor por defecto van después de los obligatorios.
  • No envíes el mismo parámetro dos veces: restar(5, a=3) da TypeError.
  • Si una llamada falla, lee el mensaje: Python te dice qué argumento falta o sobra.
◆ IDEA CLAVE

Ante la duda, usa palabras clave: la llamada se lee sola.

PARÁMETROS ● GUÍA DE REPASO

Práctica 02 · Precio con descuento

Combina un parámetro obligatorio con uno por defecto.

✦ DESAFÍO · INTÉNTALO SIN MIRAR

Escribe precio_final(precio, descuento=0.1) que devuelva el precio con el descuento aplicado. Imprime precio_final(100), precio_final(100, 0.25) y precio_final(descuento=0.5, precio=80).

PYTHON
def precio_final(precio, descuento=0.1):
    return precio * (1 - descuento)

print(precio_final(100))
print(precio_final(100, 0.25))
print(precio_final(descuento=0.5, precio=80))
↳ SALIDA ESPERADA
90.0
75.0
40.0
PISTA / IDEA CLAVE

La tercera llamada usa palabras clave en otro orden y sigue funcionando.

03 / return y None

Lo que la función te entrega al terminar.

RETURN ● GUÍA DE REPASO

return termina la función

Cuando Python llega a return, sale de la función de inmediato.

EN POCAS PALABRAS
  • El valor después de return vuelve al lugar de la llamada.
  • El código escrito después de return nunca se ejecuta.
PYTHON
def mi_funcion():
    print("¡Hola!")
    return "Adiós"
    print("Este mensaje no se imprimirá.")  # código inalcanzable

valor = mi_funcion()
print(valor)
↳ SALIDA ESPERADA
¡Hola!
Adiós
◆ IDEA CLAVE

Piensa en return como la puerta de salida: lo que lleves en la mano es lo que entregas.

RETURN ● GUÍA DE REPASO

Varios valores = una tupla

Si devuelves varios valores separados por comas, Python los empaqueta en una tupla.

EN POCAS PALABRAS
  • datos recibe la tupla completa.
  • También puedes desempaquetarla en variables separadas.
PYTHON
def get_datos_personales():
    nombre = "Ana"
    edad = 30
    ciudad = "Madrid"
    return nombre, edad, ciudad

datos = get_datos_personales()
print(datos)
nombre, edad, ciudad = get_datos_personales()
print(nombre, "vive en", ciudad)
↳ SALIDA ESPERADA
('Ana', 30, 'Madrid')
Ana vive en Madrid
◆ IDEA CLAVE

Es la misma tupla de la Clase 1, solo que creada por una función.

RETURN ● GUÍA DE REPASO

Sin return, la función devuelve None

Aunque no escribas return, Python siempre devuelve algo: el valor especial None.

EN POCAS PALABRAS
  • None significa «nada» o «ausencia de valor».
  • Una función que solo imprime hace algo visible, pero no entrega nada.
  • Guardar su resultado en una variable da None.
PYTHON
def mostrar_alerta(mensaje):
    """Muestra un mensaje de advertencia en la pantalla."""
    print(f"[ALERTA]: {mensaje}")

resultado = mostrar_alerta("Batería baja")
print(resultado)
↳ SALIDA ESPERADA
[ALERTA]: Batería baja
None
◆ IDEA CLAVE

return sin valor también devuelve None.

RETURN ● GUÍA DE REPASO

print frente a return

Es la confusión más común: mostrar un valor no es lo mismo que devolverlo.

EN POCAS PALABRAS
  • print muestra en pantalla y la función devuelve None.
  • return entrega el valor para que lo uses después.
  • Solo con return puedes hacer doble(5) + 1.
PYTHON
def doble_con_print(x):
    print(x * 2)

def doble_con_return(x):
    return x * 2

a = doble_con_print(5)
b = doble_con_return(5)
print(a, b)
print(b + 1)
↳ SALIDA ESPERADA
10
None 10
11
↪ ACLARACIÓN DEL COLAB En el Colab hay una celda con return escrito fuera de una función, junto a la analogía del trabajador. Al ejecutarla, Python da SyntaxError: 'return' outside function: return solo puede ir dentro de una función.
RETURN ● GUÍA DE REPASO

04 / Closures

Funciones que recuerdan de dónde vienen.

CLOSURES ● GUÍA DE REPASO

¿Qué es un closure?

Una función anidada que recuerda las variables de la función que la creó, incluso cuando esa función ya terminó.

EN POCAS PALABRAS
  • Mensajero privado: la oficina (función exterior) cierra, pero el mensajero (función interior) se lleva el documento que necesita.
  • Fotógrafo de bodas: la dirección de los novios queda apuntada en el cuaderno del asistente aunque la oficina ya no opere.
  • Ese «paquete de memoria» que viaja con la función interior es el closure.
◆ IDEA CLAVE

Tres ingredientes: una función dentro de otra, que usa una variable de afuera y que se devuelve sin ejecutarla.

CLOSURES ● GUÍA DE REPASO

Una fábrica de multiplicadores

La función exterior recibe a y devuelve una función que multiplica por ese a.

EN POCAS PALABRAS
  • crear_multiplicador(2) devuelve una función, no un número.
  • doble recuerda que a = 2; triple recuerda que a = 3.
  • Se devuelve mult sin paréntesis: la función misma, sin ejecutarla.
PYTHON
def crear_multiplicador(a):
    def mult(x):
        return a * x
    return mult

doble = crear_multiplicador(2)
triple = crear_multiplicador(3)
print(doble(10), doble(5), doble(3))
print(triple(10))
↳ SALIDA ESPERADA
20 10 6
30
↪ ACLARACIÓN DEL COLAB En el Colab la función se define como cierre_calculo, pero se llama cierre_calc(): ejecutada tal cual, la celda da NameError. La salida «20 10 6» que se ve guardada viene de una ejecución anterior. Además, la línea a = 2 dentro de la función anulaba el parámetro. Aquí se corrigen ambos detalles.
CLOSURES ● GUÍA DE REPASO

El fotógrafo que recuerda tu nombre 📸

Cada closure guarda su propio dato: un fotógrafo para Laura y otro para Luis.

EN POCAS PALABRAS
  • contratar_fotografo es la función exterior.
  • tomar_foto es el closure: usa nombre_cliente.
  • Cada llamada a la fábrica crea un closure con su propia memoria.
PYTHON
def contratar_fotografo(nombre_cliente):
    def tomar_foto(evento):
        return f"Foto de {evento} tomada para {nombre_cliente}."
    return tomar_foto

fotografo_para_laura = contratar_fotografo("Laura")
fotografo_para_luis = contratar_fotografo("Luis")
print(fotografo_para_laura("la boda"))
print(fotografo_para_luis("la graduación"))
↳ SALIDA ESPERADA
Foto de la boda tomada para Laura.
Foto de la graduación tomada para Luis.
◆ IDEA CLAVE

contratar_fotografo ya terminó, pero cada fotógrafo sigue sabiendo para quién trabaja.

CLOSURES ● GUÍA DE REPASO

¿Para qué sirven los closures?

Son la base de herramientas más avanzadas de Python.

EN POCAS PALABRAS
  • Encapsular datos: el dato queda guardado dentro de la función, sin variables globales.
  • Funciones a medida: creas versiones especializadas (un fotógrafo por cliente).
  • Decoradores: modifican otras funciones y se construyen con closures.
◆ IDEA CLAVE

Si necesitas muchas funciones casi iguales, piensa en una fábrica con closures.

CLOSURES ● GUÍA DE REPASO

Práctica 04 · Calculadora de impuestos

Construye tu propia fábrica de funciones.

✦ DESAFÍO · INTÉNTALO SIN MIRAR

Escribe crear_impuesto(tasa) que devuelva una función que reciba un precio y le sume el impuesto. Crea iva = crear_impuesto(0.19) y reducido = crear_impuesto(0.05) e imprime ambos para un precio de 100.

PYTHON
def crear_impuesto(tasa):
    def aplicar(precio):
        return round(precio * (1 + tasa), 2)
    return aplicar

iva = crear_impuesto(0.19)
reducido = crear_impuesto(0.05)
print(iva(100))
print(reducido(100))
↳ SALIDA ESPERADA
119.0
105.0
PISTA / IDEA CLAVE

La función interior usa tasa, que pertenece a la función exterior: eso es el closure.

05 / Reto final

Todo junto en un solo programa.

RETO FINAL ● GUÍA DE REPASO

Reto · Boletín de notas

Usa parámetros por defecto, varios valores de retorno y una función auxiliar.

✦ DESAFÍO · INTÉNTALO SIN MIRAR

Escribe boletin(nombre, notas, minimo=60) que devuelva el promedio y el estado ("Aprobado" o "Reprobado"). Imprime el boletín de Ana [85, 90, 78] y de Luis [50, 62, 58] con el formato Ana: 84.3 → Aprobado.

PYTHON
def promedio(valores):
    return sum(valores) / len(valores)

def boletin(nombre, notas, minimo=60):
    prom = promedio(notas)
    estado = "Aprobado" if prom >= minimo else "Reprobado"
    return prom, estado

for nombre, notas in [("Ana", [85, 90, 78]), ("Luis", [50, 62, 58])]:
    prom, estado = boletin(nombre, notas)
    print(f"{nombre}: {prom:.1f} → {estado}")
↳ SALIDA ESPERADA
Ana: 84.3 → Aprobado
Luis: 56.7 → Reprobado
PISTA / IDEA CLAVE

Divide el problema: una función calcula el promedio y otra decide el estado.

CIERRE ● GUÍA DE REPASO
