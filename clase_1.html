01 / Listas

Secuencias ordenadas que podemos modificar.

LISTAS ● GUÍA DE REPASO

¿Qué es una lista?

Una lista agrupa varios valores bajo un solo nombre. Conserva el orden de los elementos y permite cambiarlos.

EN POCAS PALABRAS
  • Se crea con corchetes: [ ].
  • Puede contener distintos tipos de datos.
  • Su primer elemento tiene índice 0.
PYTHON
frutas = ["Melocotón", "Sandia", "Banana", "Papaya"]
print(frutas[0])
↳ SALIDA ESPERADA
Melocotón
◆ IDEA CLAVE

Una lista es mutable: puedes agregar, eliminar o reemplazar elementos.

LISTAS ● GUÍA DE REPASO

len() · ¿Cuántos elementos hay?

len(secuencia) devuelve el número de elementos; no el índice de la última posición.

EN POCAS PALABRAS
  • Una lista de 3 elementos tiene longitud 3.
  • Sus índices válidos son 0, 1 y 2.
PYTHON
frutas = ["manzana", "cambur", "patilla"]
print(len(frutas))
print(frutas[2])
↳ SALIDA ESPERADA
3
patilla
◆ IDEA CLAVE

Último índice = len(lista) - 1 (cuando la lista no está vacía).

LISTAS ● GUÍA DE REPASO

Índices positivos y negativos

Los índices positivos cuentan desde el inicio; los negativos cuentan desde el final.

EN POCAS PALABRAS
  • frutas[0] → primero.
  • frutas[-1] → último.
  • frutas[-2] → penúltimo.
PYTHON
frutas = ["manzana", "cambur", "patilla"]
print(frutas[0])
print(frutas[-1])
↳ SALIDA ESPERADA
manzana
patilla
◆ IDEA CLAVE

Si pides una posición inexistente, aparece IndexError.

LISTAS ● GUÍA DE REPASO

Rebanadas (slicing) y rangos

Con [inicio:fin] seleccionas posiciones desde inicio hasta ANTES de fin.

EN POCAS PALABRAS
  • El límite derecho nunca se incluye.
  • lista[1:3] toma los índices 1 y 2.
  • También funciona en del para borrar un rango.
PYTHON
frutas = ["manzana", "pera", "plátano", "uva"]
print(frutas[1:3])
del frutas[0:2]
print(frutas)
↳ SALIDA ESPERADA
['pera', 'plátano']
['plátano', 'uva']
◆ IDEA CLAVE

Piensa en [inicio:fin); esta idea explica muchas operaciones con secuencias.

LISTAS ● GUÍA DE REPASO

Concatenar listas con +

El operador + crea una lista nueva con los elementos de ambas listas, en ese orden.

EN POCAS PALABRAS
  • No modifica necesariamente las listas originales.
  • Es distinto de sumar números elemento por elemento.
PYTHON
lista1 = [1, 2, 3]
lista2 = [4, 5, 6]
combinada = lista1 + lista2
print(combinada)
↳ SALIDA ESPERADA
[1, 2, 3, 4, 5, 6]
◆ IDEA CLAVE

Este ejemplo aparece en el Colab como «Adición de listas».

LISTAS ● GUÍA DE REPASO

append() · Añadir un elemento

append(x) coloca x como UN solo elemento al final.

EN POCAS PALABRAS
  • Modifica la lista existente.
  • No devuelve la lista: su valor de retorno es None.
PYTHON
carros = ["Ferrari", "Lamborghini"]
carros.append("Rolls-Royce")
print(carros)
↳ SALIDA ESPERADA
['Ferrari', 'Lamborghini', 'Rolls-Royce']
◆ IDEA CLAVE

Úsalo cuando quieres añadir un único elemento.

LISTAS ● GUÍA DE REPASO

extend() · Añadir varios elementos

extend(iterable) recorre los elementos de otro iterable y los agrega uno por uno.

EN POCAS PALABRAS
  • append([3,4]) agrega una lista dentro de la lista.
  • extend([3,4]) agrega dos números separados.
PYTHON
a = [1, 2]
b = [1, 2]
a.append([3, 4])
b.extend([3, 4])
print(a)
print(b)
↳ SALIDA ESPERADA
[1, 2, [3, 4]]
[1, 2, 3, 4]
◆ IDEA CLAVE

Comparar append y extend evita errores cuando trabajas con listas anidadas.

LISTAS ● GUÍA DE REPASO

del · Eliminar por posición

del es una instrucción de Python, no un método. Elimina según índices o rangos.

EN POCAS PALABRAS
  • del frutas[1] borra el segundo elemento.
  • del frutas[0:2] borra los dos primeros.
  • No devuelve el elemento eliminado.
PYTHON
frutas = ["manzana", "cambur", "cereza", "fresa"]
del frutas[1]
print(frutas)
↳ SALIDA ESPERADA
['manzana', 'cereza', 'fresa']
◆ IDEA CLAVE

Usa del cuando NO necesitas guardar lo que borraste.

LISTAS ● GUÍA DE REPASO

pop() · Eliminar y recuperar

pop(indice) quita el elemento indicado y lo devuelve. Sin índice quita el último.

EN POCAS PALABRAS
  • Admite índices negativos.
  • En el Colab se usa pop(-3) y también pop().
  • En una lista vacía produce IndexError.
PYTHON
carros = ["Toyota", "Honda", "Ford"]
eliminado = carros.pop()
print(eliminado)
print(carros)
↳ SALIDA ESPERADA
Ford
['Toyota', 'Honda']
◆ IDEA CLAVE

pop es útil cuando vas a utilizar después el elemento retirado.

LISTAS ● GUÍA DE REPASO

remove() vs. clear()

Son métodos diferentes, aunque aparecen juntos en el material de clase.

EN POCAS PALABRAS
  • remove(valor) borra la primera coincidencia.
  • clear() borra TODOS los elementos.
  • remove lanza ValueError si el valor no existe.
PYTHON
frutas = ["Mango", "kiwi", "cambur", "kiwi"]
frutas.remove("kiwi")
print(frutas)
frutas.clear()
print(frutas)
↳ SALIDA ESPERADA
['Mango', 'cambur', 'kiwi']
[]
↪ ACLARACIÓN DEL COLAB En el Colab el título dice «Método Remove», pero el ejemplo de esa celda ejecuta clear(). Aquí se distinguen ambos.
LISTAS ● GUÍA DE REPASO

Otros métodos: count, sort, reverse

El Colab enumera estos métodos. Aquí tienes su efecto práctico.

EN POCAS PALABRAS
  • count(x) cuenta coincidencias.
  • sort() ordena la lista en su lugar.
  • reverse() invierte el orden actual (no ordena).
PYTHON
numeros = [3, 1, 3, 2]
print(numeros.count(3))
numeros.sort()
print(numeros)
numeros.reverse()
print(numeros)
↳ SALIDA ESPERADA
2
[1, 2, 3, 3]
[3, 3, 2, 1]
◆ IDEA CLAVE

sort() y reverse() modifican la lista original y devuelven None.

LISTAS ● GUÍA DE REPASO

Práctica 01 · Control de inventario

Resuelve primero de memoria y descubre la respuesta cuando estés listo.

✦ DESAFÍO · INTÉNTALO SIN MIRAR

Partiendo de items = ["cuaderno", "lápiz"], añade "borrador"; elimina "lápiz" por valor y muestra cuántos elementos quedan.

PYTHON
items = ["cuaderno", "lápiz"]
items.append("borrador")
items.remove("lápiz")
print(len(items))  # 2
PISTA / IDEA CLAVE

Pista: necesitas append(), remove() y len().

02 / Tuplas

Otra secuencia ordenada, pero inmutable.

TUPLAS ● GUÍA DE REPASO

Tuplas: datos que no se modifican

Una tupla guarda valores en orden, permite indexarlos, pero no permite cambiar sus elementos directamente.

EN POCAS PALABRAS
  • Suele escribirse con paréntesis ( ).
  • También acepta valores mezclados.
  • La indexación positiva y negativa funciona como en listas.
PYTHON
meses = ("Enero", "Febrero", "Marzo")
print(meses[0])
print(meses[-1])
↳ SALIDA ESPERADA
Enero
Marzo
◆ IDEA CLAVE

Inmutable significa que meses[0] = "Otro" no está permitido.

TUPLAS ● GUÍA DE REPASO

Recorrer una tupla con for

Un bucle for permite leer cada elemento de la secuencia, uno por uno.

EN POCAS PALABRAS
  • for mes in meses toma cada mes en orden.
  • La variable mes cambia en cada iteración.
PYTHON
meses = ("Enero", "Febrero", "Marzo")
for mes in meses:
    print(mes)
↳ SALIDA ESPERADA
Enero
Febrero
Marzo
◆ IDEA CLAVE

En clase recorrieron los doce meses; aquí usamos tres para que el patrón se vea mejor.

TUPLAS ● GUÍA DE REPASO

Lista o tupla: ¿cuál conviene?

Las dos son secuencias: el criterio principal es si necesitas modificar la colección.

EN POCAS PALABRAS
  • LISTA [ ]: nombres de alumnos que pueden agregarse o borrarse.
  • TUPLA ( ): coordenadas fijas o meses del año.
  • Ambas tienen len(), índices, slicing y recorrido con for.
PYTHON
lista = [10, 20]
tupla = (10, 20)
lista[0] = 99
print(lista)
print(tupla[0])
↳ SALIDA ESPERADA
[99, 20]
10
◆ IDEA CLAVE

Una tupla no hace inmutables automáticamente los objetos mutables que pueda contener.

03 / Diccionarios

Datos organizados en pares clave–valor.

DICCIONARIOS ● GUÍA DE REPASO

¿Qué es un diccionario?

Relaciona una clave con un valor. Para buscar no usas posiciones numéricas, sino la clave.

EN POCAS PALABRAS
  • Se escribe como {clave: valor}.
  • Las claves deben ser hashables y son únicas dentro de un diccionario.
  • Puedes añadir, modificar y eliminar pares.
PYTHON
persona = {"nombre": "Ana", "edad": 28}
print(persona["nombre"])
persona["edad"] = 29
persona["profesion"] = "Derecho"
print(persona)
↳ SALIDA ESPERADA
Ana
{'nombre': 'Ana', 'edad': 29, 'profesion': 'Derecho'}
◆ IDEA CLAVE

Clave = cómo identifico el dato; valor = información que guardo.

DICCIONARIOS ● GUÍA DE REPASO

keys() y values()

Devuelven vistas de las claves o de los valores presentes.

EN POCAS PALABRAS
  • keys() → recorrer los nombres de las claves.
  • values() → recorrer los datos almacenados.
  • No son listas: son objetos vista relacionados con el diccionario.
PYTHON
persona = {"nombre": "Ana", "edad": 28}
print(list(persona.keys()))
print(list(persona.values()))
↳ SALIDA ESPERADA
['nombre', 'edad']
['Ana', 28]
◆ IDEA CLAVE

Usamos list() para que la salida se lea con claridad.

DICCIONARIOS ● GUÍA DE REPASO

Recorrer claves y valores

En el Colab se recorre el diccionario de contactos de tres maneras.

EN POCAS PALABRAS
  • for clave in contactos recorre claves (igual que .keys()).
  • for valor in contactos.values() recorre valores.
  • La indentación señala el cuerpo del for.
PYTHON
contactos = {"Juan": "+58", "Ana": "+507"}
for nombre in contactos:
    print(nombre)
for telefono in contactos.values():
    print(telefono)
↳ SALIDA ESPERADA
Juan
Ana
+58
+507
◆ IDEA CLAVE

Cuando solo quieres las claves, escribir .keys() es opcional.

DICCIONARIOS ● GUÍA DE REPASO

items() · Clave y valor a la vez

items() entrega pares de (clave, valor). Puedes desempaquetarlos en dos variables.

EN POCAS PALABRAS
  • Cada vuelta produce un par de datos.
  • for clave, valor in ... asigna ambos.
PYTHON
contactos = {"Juan": "+58", "Ana": "+507"}
for nombre, telefono in contactos.items():
    print(nombre, "→", telefono)
↳ SALIDA ESPERADA
Juan → +58
Ana → +507
◆ IDEA CLAVE

Este patrón es muy común cuando recorres registros o configuraciones.

DICCIONARIOS ● GUÍA DE REPASO

setdefault() · Buscar o crear

Si existe la clave, devuelve su valor actual. Si no existe, crea la clave con el valor predeterminado.

EN POCAS PALABRAS
  • No sobrescribe una clave que ya existe.
  • Si omites el segundo argumento, el valor nuevo es None.
  • En el Colab, Ana ya tenía 66, así que sigue valiendo 66.
PYTHON
puntos = {"Ana": 66, "Luis": 88}
print(puntos.setdefault("Ana", 95))
print(puntos.setdefault("Pedro", 0))
print(puntos)
↳ SALIDA ESPERADA
66
0
{'Ana': 66, 'Luis': 88, 'Pedro': 0}
↪ ACLARACIÓN DEL COLAB En la celda original se comenta que Ana devuelve 95, pero con el diccionario que aparece devuelve 66. Además, setdefault("Pedro") asigna None, no 0.
DICCIONARIOS ● GUÍA DE REPASO

get() · Consulta sin KeyError

Busca una clave sin fallar cuando no existe: devuelve None o un valor por defecto.

EN POCAS PALABRAS
  • dic[clave] genera KeyError cuando falta la clave.
  • dic.get(clave) retorna None.
  • dic.get(clave, defecto) retorna el defecto indicado.
PYTHON
persona = {"nombre": "Ana", "edad": 28}
print(persona.get("nombre"))
print(persona.get("ciudad"))
print(persona.get("ciudad", "Sin registrar"))
↳ SALIDA ESPERADA
Ana
None
Sin registrar
◆ IDEA CLAVE

get consulta; setdefault puede modificar el diccionario.

DICCIONARIOS ● GUÍA DE REPASO

pop() · Eliminar una clave

Elimina el par solicitado y devuelve el valor asociado.

EN POCAS PALABRAS
  • Es diferente del pop() de listas, que recibe índices.
  • Si la clave falta, puedes pasar un valor por defecto.
PYTHON
persona = {"nombre": "Ana", "edad": 28}
edad = persona.pop("edad")
print(edad)
print(persona)
↳ SALIDA ESPERADA
28
{'nombre': 'Ana'}
◆ IDEA CLAVE

En diccionarios, pop("edad") usa una clave; en listas pop(1) usa posición.

DICCIONARIOS ● GUÍA DE REPASO

update() y clear()

Con update añades o reemplazas pares. Con clear vacías el diccionario.

EN POCAS PALABRAS
  • update conserva claves que no se mencionan.
  • Cuando llega una clave existente, actualiza su valor.
  • clear() deja {}.
PYTHON
persona = {"nombre": "Ana"}
persona.update({"edad": 28, "ciudad": "Madrid"})
print(persona)
persona.clear()
print(persona)
↳ SALIDA ESPERADA
{'nombre': 'Ana', 'edad': 28, 'ciudad': 'Madrid'}
{}
◆ IDEA CLAVE

Las operaciones ocurren sobre el mismo diccionario.

DICCIONARIOS ● GUÍA DE REPASO

Mapa mental de métodos

Cuatro preguntas que ayudan a decidir qué método utilizar.

EN POCAS PALABRAS
  • ¿Quiero leer sin error? → get.
  • ¿Quiero crear si falta? → setdefault.
  • ¿Quiero fusionar cambios? → update.
  • ¿Quiero eliminar? → pop o clear.
PYTHON
registro = {"usuario": "Ana"}
registro.setdefault("activo", True)
registro.update({"visitas": 3})
print(registro.get("visitas"))
↳ SALIDA ESPERADA
3
◆ IDEA CLAVE

No memorices solo los nombres: recuerda el problema que resuelve cada método.

DICCIONARIOS ● GUÍA DE REPASO

Práctica 02 · Contactos

Comprueba si entiendes claves, valores y actualización de datos.

✦ DESAFÍO · INTÉNTALO SIN MIRAR

Crea contactos con Ana → 507 y Luis → 600. Añade Pedro → 612 usando una clave nueva. Recorre e imprime "Ana: 507", etc.

PYTHON
contactos = {"Ana": 507, "Luis": 600}

04 / JSON

Datos que viajan entre programas y archivos.

JSON ● GUÍA DE REPASO

JSON no es un diccionario Python

JSON es un formato de texto estándar para representar datos; se parece a un diccionario, pero no es lo mismo.

EN POCAS PALABRAS
  • JSON: {"nombre": "Ana"} es texto con reglas concretas.
  • Python: {"nombre": "Ana"} puede ser un objeto dict.
  • En JSON se usan true, false y null; en Python True, False, None.
PYTHON
import json
texto = '{"nombre": "Ana", "activo": true}'
datos = json.loads(texto)
print(type(datos).__name__)
print(datos["activo"])
↳ SALIDA ESPERADA
dict
True
◆ IDEA CLAVE

json.loads() convierte texto JSON a tipos de Python.

JSON ● GUÍA DE REPASO

loads() → de JSON a Python

La s de loads recuerda que trabajas con una cadena (str).

EN POCAS PALABRAS
  • Entrada: texto JSON válido.
  • Salida: dict, list u otro tipo Python, según el JSON.
PYTHON
import json
cadena = '{"nombre": "Ana", "edad": 28}'
persona = json.loads(cadena)
print(persona["nombre"])
↳ SALIDA ESPERADA
Ana
◆ IDEA CLAVE

No confundas json.loads (cadena) con json.load (archivo).

JSON ● GUÍA DE REPASO

dumps() → de Python a JSON

Convierte valores Python en una cadena con formato JSON.

EN POCAS PALABRAS
  • La salida de dumps es un str.
  • Una lista o un diccionario puede convertirse.
  • Con ensure_ascii=False puedes conservar caracteres como ñ y acentos.
PYTHON
import json
datos = {"ciudad": ["Madrid", "París"], "activo": True}
texto = json.dumps(datos, ensure_ascii=False)
print(texto)
↳ SALIDA ESPERADA
{"ciudad": ["Madrid", "París"], "activo": true}
↪ ACLARACIÓN DEL COLAB En el Colab, un comentario sobre la salida omite que ciudad es una lista; aquí se muestra la cadena JSON real.
JSON ● GUÍA DE REPASO

JSON y listas

En los cuadernos convierten una lista de frutas a JSON y viceversa.

EN POCAS PALABRAS
  • loads puede devolver una lista, no siempre un diccionario.
  • dumps convierte la lista en texto JSON.
PYTHON
import json
texto = '["manzana", "banana", "cereza"]'
frutas = json.loads(texto)
print(type(frutas).__name__)
print(json.dumps(frutas))
↳ SALIDA ESPERADA
list
["manzana", "banana", "cereza"]
◆ IDEA CLAVE

Regla: cargas JSON hacia objetos Python; vuelcas objetos Python hacia JSON.

JSON ● GUÍA DE REPASO

load() y dump() · Archivos

Estos métodos trabajan con un archivo abierto, no directamente con una cadena.

EN POCAS PALABRAS
  • json.dump(datos, archivo) escribe JSON.
  • json.load(archivo) lee y convierte el contenido.
  • with open(...) cierra el archivo automáticamente.
PYTHON
import json
datos = {"nombre": "Ana"}
with open("data.json", "w", encoding="utf-8") as f:
    json.dump(datos, f)
with open("data.json", "r", encoding="utf-8") as f:
    recuperado = json.load(f)
print(recuperado)
↳ SALIDA ESPERADA
{'nombre': 'Ana'}
↪ ACLARACIÓN DEL COLAB El Colab original solo lee data.json. Ese ejemplo requiere que exista antes; aquí se crea y después se lee.
JSON ● GUÍA DE REPASO

Práctica 03 · Guardar una lista

Piensa en cómo almacenar temporalmente los datos para utilizarlos después.

✦ DESAFÍO · INTÉNTALO SIN MIRAR

Convierte ["rojo", "verde", "azul"] a JSON; recupera el texto convertido y comprueba que vuelves a tener una lista.

PYTHON
import json
colores = ["rojo", "verde", "azul"]
texto = json.dumps(colores)
resultado = json.loads(texto)
print(type(resultado).__name__)
print(resultado)
PISTA / IDEA CLAVE

Pista: dumps primero, loads después.

05 / Conjuntos

Elementos únicos, sin una posición fija.

CONJUNTOS ● GUÍA DE REPASO

¿Qué es un set?

Un conjunto almacena elementos únicos; el orden al imprimirlos no es una garantía.

EN POCAS PALABRAS
  • Se escribe como {1, 2, 3} o set(iterable).
  • No puedes acceder con conjunto[0].
  • Para un conjunto vacío usa set(); {} crea un diccionario.
PYTHON
colores = {"rojo", "verde", "azul"}
print(len(colores))
vacio = set()
print(type(vacio).__name__)
↳ SALIDA ESPERADA
3
set
◆ IDEA CLAVE

Un set es útil para pertenencia, unicidad y operaciones de conjuntos.

CONJUNTOS ● GUÍA DE REPASO

add() y remove()

Agregar y eliminar elementos únicos.

EN POCAS PALABRAS
  • add(x) no duplica x si ya estaba.
  • remove(x) elimina ese elemento o produce KeyError.
  • Si quieres evitar ese error al borrar, usa discard(x) (refuerzo).
PYTHON
carros = {"Toyota", "Honda", "Ford"}
carros.add("Chevrolet")
carros.remove("Toyota")
print("Toyota" in carros)
print("Ford" in carros)
↳ SALIDA ESPERADA
False
True
◆ IDEA CLAVE

in verifica pertenencia a un conjunto; es también válido para listas y tuplas.

CONJUNTOS ● GUÍA DE REPASO

Eliminar duplicados con set()

Convertir una lista a conjunto conserva solo elementos distintos.

EN POCAS PALABRAS
  • Muy útil para números, nombres o identificadores repetidos.
  • No conserva necesariamente el orden original.
PYTHON
numeros = [1, 2, 2, 3, 4, 4, 5]
unicos = set(numeros)
print(len(unicos))
print(4 in unicos)
↳ SALIDA ESPERADA
5
True
◆ IDEA CLAVE

No confíes en un orden concreto al imprimir el conjunto.

CONJUNTOS ● GUÍA DE REPASO

Unión | · Todo lo que está en A o B

La unión reúne todos los elementos, sin repetir los compartidos.

EN POCAS PALABRAS
  • Método A.union(B).
  • Operador equivalente: A | B.
PYTHON
A = {"perro", "gato", "loro"}
B = {"gato", "conejo", "serpiente"}
union = A | B
print(len(union))
print("gato" in union)
↳ SALIDA ESPERADA
5
